Firmware V6.1 corrigido do robô, com ESP-NOW, telemetria, freio anticolisão e fail-safe.

Seu navegador não oferece Web Serial. Abra no Chrome ou Edge. A instalação USB precisa ser aberta em uma página HTTPS.

Como instalar

  1. Conecte somente a ESP32 que você deseja programar.
  2. Clique no botão correspondente acima.
  3. Escolha a porta USB/COM da placa.
  4. Confirme a instalação.
  5. Espere terminar antes de desconectar o cabo.
Segurança: faça o primeiro teste do robô com as rodas levantadas do chão. Não escolha o firmware do ESP32-C3 para a placa WROOM-32, nem o firmware do robô para o C3.
